# Reusable Skill: 80mm Thermal Receipt Formatter (thermal-receipt-formatter)

## Purpose
Formats POS walk-in receipts and workshop payment receipts for standard 80mm ESC/POS thermal printers.

## Layout Specs
- Width: `80mm` (~302px).
- Font: Clean monospace (`font-mono`) or tabular sans, size 9pt–10pt.
- Header: Workshop Name, Address, Contact, Receipt Number, Date/Time.
- Divider: `--------------------------------`
- Items: Table with Item, Qty x Price, Line Total.
- Totals: Subtotal, Discount, Net Total, Amount Tendered, Change.
- Footer: Thank you message & barcode placeholder.
